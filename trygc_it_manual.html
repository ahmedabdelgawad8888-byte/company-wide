Standard Operating Procedures (SOPs)

Onboarding & Offboarding

New Employee Onboarding

  1. Receive HR request for specific region (KSA, KW, UAE, Mansoura).
  2. Provision laptop, mobile device, accounts, and access permissions.
  3. Connect to branch Wi-Fi and validate connectivity.
  4. Log assets in the IT Asset Management System.
  5. Mark task `Completed` only after final setup verification by user.

Offboarding

  1. Receive offboarding ticket.
  2. Instantly revoke accounts, access, email forwards.
  3. Lock/Wipe device via MDM / Sophos.
  4. Recover physical assets and update inventory.
Infrastructure & Backups
  • Backups: Daily Veeam checks, immutable Debian/TrueNAS jobs. Log every failure in OsTicket.
  • Servers: Weekly UAE server health checks, restore-to-VM testing.
  • Network: Daily router tests, VLAN troubleshooting, DHCP pool management.
  • Security: Enforce Sophos on all endpoints. Enforce MDM policies on mobile assets.
Asset Management & MDM
  • No duplicate names allowed in the live IT Asset Management System.
  • Track laptop locations across all branches.
  • Use ManageEngine/Custom MDM for remote mobile control.
  • Run periodic physical reconciliation per branch (Mansoura, Cairo, KSA, KW, UAE).
Social Media, WhatsApp & Sharing
  • Configure new social accounts (Instagram, WhatsApp Pro) with mandatory branding and 2FA.
  • Audit active/restricted accounts and revoke access for departed staff.
  • WhatsApp: Convert personal to business, verify Meta status.
  • pCloud: Remove duplicates, manage folder sizes, transfer file ownership only with IT Lead sign-off.
Finance & Subscriptions
  • Reconcile payment history and file new invoices automatically.
  • Update payment cards for subscribed platforms (Requires Finance Holder coordination).
  • Proactively request refunds for unused seats (e.g., ClickUp).
